# v1.4.6.26

本版本重新整理封面来源与刮削流程，避免 JAV321 的不稳定结果影响正常搜索和归档。

- JAV321 不再参与首页、普通搜索、详情补全或自动刮削，旧配置会自动移除该来源。
- 刮削设置新增 JAV321 手动封面补救，只处理仍在监控目录、任务明确显示封面失败、且本地没有 poster 的视频。
- JAV321 补救会严格核对番号和图片有效性；成功后按当前裁切设置生成 poster 与 fanart，并继续原有刮削、规整和归档。
- 多来源结果分别保留封面候选，首页和详情会逐一重试有效图片，不再因某一来源失效而直接显示无封面。
- 一张有效封面即可完成 poster 与 fanart：开启裁切时保留原图作为 fanart 并裁出 poster；独立背景图失败会复用主封面。
- 设置界面改为标准整页，移动端栏目切换、保存和各项操作按钮保持可用。
