# v1.4.6.22

- 番号搜索改为忽略大小写和分隔符后的完整字母数字匹配，拒绝相似但不相同的结果，并支持 `T28-304` 一类“字母+数字-数字”番号。
- 详情页样品图优先从 JAV321 获取；JAV321 无图时按需回退 JavDB。
- 群晖归档文件夹名上限收紧到 180 个 UTF-8 字节，避免中文长标题超过共享目录限制。
- 迅雷及手动放入的文件改为整目录连续稳定后再统一处理；新分段或任一文件变化会重置 5 分钟静置窗口，稳定前禁止刮削、归档和广告删除。
- 文件名中的明确番号优先于外层目录；`PART01`、`CD01` 等纯分段名继承目录番号，顶层同番号文件和嵌套分段归入同一稳定批次。
- 下载器任务路径匹配出现歧义时一律按“下载中”处理；未完成标记存在时整批暂停。
- 保留广告大小阈值：低于设定值的无番号、无分段标记候选按广告删除；明确广告标记也可删除，但 CD/PART/A-B 分段和硬字幕始终保护。
- 移动归档后仅删除完全无文件的空目录，存在任何未知文件或下载器残留时保留原目录。
- 删除已经不参与运行的“最多有效补查来源”设置；自动刮削缺封面仍固定按 JAV321 → JavDB 回退，详情页样品图继续按已启用来源执行 JAV321 → JavDB 回退。
- 广告/赠片删除与视频规整开关彻底解耦；关闭规整但保留广告删除时，仍在整批下载稳定后按大小、番号和分段保护规则清理广告。
- 设置页说明按实际执行链重新整理，明确搜索/首页/详情来源差异、搜索结果总上限、封套关闭后的 fanart 回退和最小文件大小行为。
- 移除当前版本没有执行模块的 M-Team、发种流水线和图床配置；旧 `publish_*` 目录与开关只在读取历史配置时迁移一次，随后不再进入运行配置或保存结果。
