# v1.4.6.29

本版本修复监控目录自动刮削中“搜索可见但刮削失败”的问题，并整合社区搜索体验改进。

- 自动刮削先在有界范围内寻找精确番号，避免 `MXGS-713` 等排序靠后的结果因过早截断而漏掉；继续拒绝相似但不同的番号，包括 `BNDV-702` 与 `BNDV-00702`。
- 兼容 JavDB 新版搜索卡片和详情页拆分显示的番号；失效高清封面后依次验证同条目缩略图、已有候选和启用来源的精确结果。
- 监控目录支持 `MXGS 713.mp4` 等单空格分隔的人工文件名。任务记录区分来源请求、页面解析、精确命中、详情与封面状态；网络及封面临时失败最多额外重试 3 次，失败时保留源视频。
- 调整搜索框以减少浏览器密码自动填充误入，增加最多 8 条本机搜索历史。问题与功能由 [coldmountein](https://github.com/coldmountein) 在 [PR #3](https://github.com/seaside111/jav-search/pull/3) 贡献；本地整合时补充了失败请求不入历史及数据校验。
- 189 项 Python 回归测试通过；临时视频实连 JavDB，`HODV-20489` 成功生成 NFO、poster 和 fanart。详细排查见 [修复记录](../scraping-review-2026-09-18.md)。
