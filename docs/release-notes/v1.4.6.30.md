# v1.4.6.30

本版本更新设置中的刮削控制与目录管理，支持多组下载、归档及 Emby 路径映射。

- 新增默认关闭的“开始刮削 / 停止刮削”总开关，点击后保存状态，重启后保持；停止时完成当前文件，再停止后续扫描。升级后请在设置中检查并开启总开关，刮削、规整和归档的独立选项仍控制具体操作。
- 支持多组“下载目录 → 归档目录”映射，可共用归档目录；校验重复及相互包含的下载目录，并排除归档目录，避免重复扫描。
- 单目录和各组多目录均可实际测试硬链接，提示群晖/Docker 跨挂载或跨文件系统失败，以及退化为复制后的额外空间占用。
- 每个下载目录新增“强制重新刮削”，绕过已处理、已归档及失败重试等待记录，按当前设置刷新 NFO、封面和归档产物。内容相同的目标视频可复用，不覆盖不同内容的视频；继续检查下载完成状态及文件稳定性。移动模式已移走的源文件不会被重新扫描。
- 多目录每组可独立填写“Emby 对应目录”，适配一个媒体库包含多个文件夹。留空使用本组归档路径；影片通知、演员头像同步及延迟重试按实际归档目录选择映射，上传的头像仍来自本地图片。共用归档目录时要求 Emby 映射一致。
- 修复手动扫描保存设置时后台扫描提前抢占的问题；历史归档配套文件修复支持多个归档根目录。
- 修复 Linux 大小写敏感文件系统下 `.!qB` / `.!uT` 未完成标记识别，以及同一分段文件仅大小写不同的目标重名保护。

验证：Windows 与 Docker/Linux 各 206 项后端测试、6 项前端交互测试通过；Docker 实测同文件系统硬链接、跨 tmpfs 失败、按组归档、强制重扫及重启持久化。下载器和 Emby 联调使用本地模拟服务与合成文件，未连接真实媒体服务。
