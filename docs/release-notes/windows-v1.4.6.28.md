# Windows v1.4.6.28

此版本把 Docker v1.4.6.25 至 v1.4.6.27 的通用搜索、封面、刮削、翻译和任务修复同步到 Windows 桌面版。

- 修复磁链复制、演员头像目录开关与强制重扫、立即扫描并发和任务失败状态。
- JAV321 改为手动封面失败补救；统一 poster/fanart 生成流程并改用标准整页设置。
- 修复旧 NFO 未写入中文译名、归档文件名未按当前设置更新的问题。
- 修复 FC2 与正常番号无码片的自动来源路由，保留前端推送时所选来源的有效封面。
- 保留 Windows 本机目录、复制/移动归档、本地下载器和经过 SHA256 校验的独立自动更新。
- Windows 更新仍只识别 `windows-v*` 标签，不影响 Docker Release 与 GHCR `latest`。
