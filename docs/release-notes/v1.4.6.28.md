# v1.4.6.28

本版本将详情页样品图和投稿磁力切换到 JavBus，并以 JAV321 作为仅样品图的最终兜底，移除该链路对 JavDB 的依赖。

- JavBus 详情页直接解析样品图库，并请求站内异步磁力接口，保留磁力名称、大小、日期、高清和字幕标记。
- 详情扩展固定按 JavBus → JAV321 顺序执行；只有 JavBus 无样品图时才检索 JAV321，仍无结果即停止。
- JAV321 保持为详情样品图兜底，不进入首页、普通搜索或可配置来源列表。
- 旧版 JavBus 详情缓存会自动失效并重新抓取，避免升级后继续返回缺少样品图和磁力的缓存结果。
- 修复 JAV321 宽栏媒体区把 DMM 大封面误判为样品图的问题。
- 使用 `SUN-067` 完成真实页面验证：JavBus 返回 20 张样品图和 10 条磁力，JAV321 兜底返回 20 张有效样品图。
