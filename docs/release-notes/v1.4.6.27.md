# v1.4.6.27

本版本修复翻译结果未写入旧 NFO、归档文件名未按设置更新，以及 FC2/无码影片自动刮削来源路由问题。

- 失败刮削留下旧 NFO 时，后续成功刮削会使用当前元数据和翻译结果重新写入；已归档的受影响任务会安全补正中文标题。
- 增加规整和视频重命名实际状态日志，并按当前设置安全修复受旧流程影响的已归档视频与 NFO 文件名。
- 保存设置不再重复刷新刮削监控，消除重复的配置变更日志。
- FC2 番号支持多种常见写法并统一进入 FC2/MissAV 专用链路，直接监控刮削不依赖首页来源开关。
- 正常番号无码片可使用已启用的 AVSOX/AVMOO 等来源兜底；前端推送保留所选来源的有效封面，避免被 JavBus 强制替换。
- 覆盖全部翻译渠道及上述刮削、封面、NFO 和归档修复的自动测试。
