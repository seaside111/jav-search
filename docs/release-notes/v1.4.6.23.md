# v1.4.6.23

- 新增 DeepL、有道、Microsoft/Bing、Google Cloud Translation 等传统翻译 API。
- 新增 DeepSeek、ChatGPT/OpenAI、Claude、Grok、Gemini 等大模型翻译渠道。
- 新增 OpenRouter、硅基流动及自定义 OpenAI 兼容中转站，支持自定义 API 地址和模型。
- 翻译请求支持复用全局代理，并可设置 5–120 秒请求超时。
- 翻译设置页改为“默认渠道 + 当前渠道配置卡片”，切换渠道时保留已填写内容，避免所有配置纵向堆叠。
- 百度、阿里云旧版配置自动兼容，升级后无需重新填写。
- 首页列表及详情页移除百度、阿里渠道切换按钮，统一为一个“翻译”按钮，由后端读取已保存的默认渠道。
- 新增嵌套 API 密钥递归脱敏和保存保护，避免设置接口返回明文或保存掩码时覆盖原密钥。
- 新增翻译适配器、默认渠道、代理及密钥保存测试，并完成既有刮削与归档功能回归。
